# LinkedIn posts

One Markdown file per author: `linkedin-posts/<author-slug>.md` (e.g. `kevin-indig.md`).

LinkedIn blocks scraping behind a login and forbids it in its ToS, so posts here are **collected manually** (pasted in), not scraped. For each post use this format:

```markdown
## <YYYY-MM-DD> — <one-line topic>
Source: <post URL>

<full post text, pasted as-is>

> Annotation: why this post matters for the playbook (1 line).
```

Drop the post text (or the post URLs) into chat and they'll be cleaned, dated, annotated, and filed here by author.
